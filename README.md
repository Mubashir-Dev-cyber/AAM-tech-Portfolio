# AAM-tech-Portfolio
AAM tech is a technology and software development company focused on helping businesses build a strong digital presence. We create modern, responsive, and user-friendly websites and digital solutions tailored to the needs of businesses, startups, and organizations.

## Running the site

Built with React + Vite.

```bash
npm install
npm run dev      # start local dev server at http://localhost:5173
npm run build    # production build into dist/
```

All site content (services, projects, contact details, social links) lives in `src/data.js`.
